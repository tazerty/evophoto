EvoPhoto portable mode

While this file sits next to evophoto.exe, EvoPhoto keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the EvoPhotoData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move EvoPhoto with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\EvoPhoto for settings
and %LOCALAPPDATA%\EvoPhoto\Recovery for crash-recovery autosaves. If EvoPhotoData can't be
written (for example on a read-only drive), EvoPhoto says so and uses those folders instead.
