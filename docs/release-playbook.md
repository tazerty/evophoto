# Release playbook

The release playbook shared by every building app lives in evorules:
[`../evorules/release/playbook.md`](../../evorules/release/playbook.md)
(`amont/evo-rules`, a sibling checkout; the repository is not public). It is the canonical copy; don't duplicate it here.

EvoPhoto is its reference implementation (`.github/workflows/release.yml`, `packaging/`,
`cargo xtask version`). EvoPhoto-specific details are in [releasing.md](releasing.md).
